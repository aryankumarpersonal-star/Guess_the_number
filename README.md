# Guess the number game
This is a simple, interactive number-guessing game I built with Python using the built-in random module.

# About the Project
In this game, the computer generates a random number, and the player tries to guess it. The program provides feedback to help the player figure out the correct number. The game also have a difficulty system that limits the number of tries the player gets
This project was created to practice Python fundamentals and explore random number generation.
